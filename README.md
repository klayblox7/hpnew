# 여유톡 홈페이지 시안

여유톡 메인 홈페이지 리뉴얼 공유용 정적 HTML 파일입니다.

## 확인 방법

1. 이 저장소를 내려받습니다.
2. `index.html` 파일을 브라우저로 엽니다.
3. `assets/` 폴더는 `index.html`과 같은 위치에 있어야 이미지와 아이콘이 정상 표시됩니다.

## 포함 파일

- `index.html`: 메인 홈페이지 시안
- `assets/`: 배너, 행사 이미지, 아이콘 파일
- `VENDOR-HANDOFF.md`: 홈페이지 업체 전달용 연동 메모

## 업체 연동 메모

현재 파일은 정적 시안입니다. 실제 운영 반영 시 기존 관리자 페이지의 행사 등록/삭제, 신청자 목록, 문자발송 기능과 연결해야 합니다.
